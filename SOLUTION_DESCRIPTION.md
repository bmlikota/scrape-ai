# Solution Description

**SheepAI: AI-Powered Cybersecurity News Aggregator**

SheepAI collects, summarizes, and enables semantic search for cybersecurity news via OpenAI embeddings and PostgreSQL pgvector. Features: AI summaries, multi-model consensus preventing hallucinations, and real-time notifications.
