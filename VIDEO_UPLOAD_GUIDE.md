# MVP Video Upload Guide

## Optionen zum Hochladen deines MVP-Videos

### 1. YouTube (Empfohlen für Hackathons)

**Vorteile:**
- ✅ Einfach zu teilen
- ✅ Gute Qualität
- ✅ Funktioniert auf allen Geräten
- ✅ Kann eingebettet werden

**Schritte:**
1. Gehe zu [YouTube Studio](https://studio.youtube.com/)
2. Klicke auf "Erstellen" → "Video hochladen"
3. Lade dein Video hoch
4. **Wichtig**: Setze die Sichtbarkeit auf **"Nicht gelistet"** (unlisted)
   - So kann jeder mit dem Link darauf zugreifen
   - Es erscheint nicht in Suchresultaten
5. Kopiere den Link (z.B. `https://www.youtube.com/watch?v=...`)
6. Füge den Link in die README.md ein (ersetze `YOUR_VIDEO_LINK_HERE`)

### 2. Google Drive

**Vorteile:**
- ✅ Keine Upload-Limits
- ✅ Direkter Download möglich

**Schritte:**
1. Lade Video zu Google Drive hoch
2. Rechtsklick auf Datei → "Link teilen"
3. Setze Berechtigung auf "Jeder mit dem Link"
4. Kopiere den Link
5. Füge Link in README.md ein

### 3. Loom (Für Screen-Recordings)

**Vorteile:**
- ✅ Speziell für Demos gemacht
- ✅ Automatische Transkription
- ✅ Einfaches Teilen

**Schritte:**
1. Gehe zu [Loom](https://www.loom.com/)
2. Lade Video hoch oder nehme direkt auf
3. Kopiere den Share-Link
4. Füge Link in README.md ein

### 4. Vimeo

**Vorteile:**
- ✅ Professioneller
- ✅ Gute Qualität

**Schritte:**
1. Gehe zu [Vimeo](https://vimeo.com/)
2. Lade Video hoch
3. Setze auf "Unlisted" oder "Password protected"
4. Kopiere den Link
5. Füge Link in README.md ein

## Link in Repository einfügen

Nachdem du den Link hast, ersetze in folgenden Dateien `YOUR_VIDEO_LINK_HERE`:

1. `README.md` (ganz oben)
2. `SOLUTION_DESCRIPTION.md`
3. `SOLUTION_COMPLETENESS.md`

**Beispiel:**
```markdown
[Watch the MVP Demo Video](https://www.youtube.com/watch?v=YOUR_VIDEO_ID)
```

## Tipps für das Video

- **Dauer**: 2-5 Minuten ideal
- **Zeige**: Hauptfeatures, UI, wie es funktioniert
- **Struktur**: Problem → Lösung → Demo → Ergebnis
- **Qualität**: Mindestens 720p, gute Audioqualität
